# Оплата привилегий: как получать деньги за «Клубную карту»

Документ для владельца игры и для того, кто будет подключать платежи. Отвечает на три вопроса:
**куда выкладывать игру**, **как принимать деньги** и **что уже готово в коде**.

Коротко: игра уже умеет продавать «Клубную карту» и честно показывает витрину. Чтобы деньги
реально приходили, нужны три вещи — **платёжный провайдер**, **маленький сервер** (он прячет
секретный ключ и выдаёт доступ после оплаты) и **регистрация в РФ** (самозанятый или ИП).

---

## 1. Куда выкладывать игру

| Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|
| **GitHub Pages** (сейчас) | бесплатно, уже работает | правила GitHub не для коммерческих игр с оплатой | пока ок для теста, для продаж — нет |
| **Свой домен + хостинг статики** (Timeweb, Beget, Reg.ru, Cloudflare Pages) | домен, свой бренд, никаких чужих правил, легко прицепить ЮKassa | ~200–500 ₽/мес, нужен домен | **лучший выбор** |
| **VK Play / Яндекс Игры** | готовая аудитория, у платформ своя монетизация | модерация, их правила оформления и доля платформы | вариант, если не хотим свой домен |
| **Telegram Mini App** | очень удобно для «подписки в один тап» | нужен бот и сервер, игры-страницы так не собрать | вариант «на вырост» |

Практичный план: **купить домен** (например `tihayazavod.ru`), положить туда `rybalka.html`
как `index.html` — больше ничего не нужно, сборка уже одиночный файл. Это те же 4,6 МБ,
что и на GitHub, просто свой адрес и без чужих правил.

## 2. Как принимать деньги (провайдер)

| Провайдер | Кому | Комиссия | Чек самозанятого | Вывод |
|---|---|---|---|---|
| **ЮKassa** | самозанятый, ИП, ООО | ~3,5% карта, СБП дешевле, без абонплаты | **нет** с 29.12.2025 — чек делать в «Мой налог» вручную | 1–2 рабочих дня |
| **Robokassa** | самозанятый, ИП | ~3,4% карта, 3% СБП | **есть** автоматический чек НПД | 1–3 дня |
| **Robokassa / ЮKassa «по ссылке»** | совсем без сайта | та же | — | так же |

Практический совет: **Robokassa для самозанятого** удобнее — она сама делает чек НПД.
Если выберешь ЮKassa — придётся вручную регистрировать доход в «Моём налоге».

> Важно, по закону: принимать деньги за игру можно, если ты **самозанятый (НПД)** или ИП.
> Самозанятому нельзя перепродавать чужие товары; продажа доступа к своей игре подходит.
> Лимит НПД — 2,4 млн ₽ в год.

## 3. Что уже готово в игре

- **Витрина «Клубная карта»**: три тарифа (99 ₽ неделя · 249 ₽ месяц · 1790 ₽ год), список привилегий,
  **код игрока** (например `DV9J-UYDD`) и кнопки «Оплатить» / «Уже оплатил — проверить оплату».
- **Доступ выдаётся только по ключу сервера**: в сохранении лежит `pass = {plan, exp, code}`;
  игра проверяет срок и то, что код совпадает с кодом этого игрока. Кнопкой доступ не включается.
- **Проверка оплаты** (`payCheck`) спрашивает сервер и, если оплата найдена, включает карту.
- **Возврат с оплаты**: если платёжная страница вернёт игрока с `?paid=1`, игра сама проверит оплату.
- **Старая дверь осталась**: премиум-предметы за жемчуг по-прежнему открывают клуб навсегда.
- Пока сервис не подключён, кнопка оплаты **выключена** и честно пишет «Оплата скоро подключится».

Проверки: `tests/pay.mjs` (18 проверок) — витрина, тарифы, код игрока, выдача ключа,
истечение срока, отказ чужому ключу, совместимость с прежними премиум-предметами.

## 4. Что нужно поднять (сервер, ~150 строк)

Маленький сервис на любом хостинге (Node.js или Python на Timeweb/Beget, либо Render).
Он нужен ровно для двух вещей: **создать платёж** и **выдать ключ после подтверждения оплаты**.
Секретные ключи провайдера живут только здесь, в игру они не попадают.

```
POST /pay/start   { plan, code }        → { url }      создать платёж, вернуть ссылку на оплату
GET  /pay/status?code=...               → { ok, key:{plan, exp}, token }
POST /pay/notify  (вебхук провайдера)   → 200          отметить оплату по метке code
```

Минимальная логика:

1. `/pay/start` — создаём платёж у провайдера на сумму тарифа, в `metadata` (или в описании)
   кладём `code` игрока и `plan`; возвращаем игроку ссылку на оплату.
2. Провайдер после оплаты зовёт `/pay/notify`; проверяем подпись/статус, пишем в базу
   «код → оплачено, план, дата».
3. `/pay/status?code=...` — если оплата есть, считаем `exp = now + дни плана` и отдаём ключ.
   Игра сохранит его и включит привилегии.

Проверка подписи вебхука обязательна: иначе кто угодно сможет «подтвердить» оплату себе.

### Готовый каркас (Node.js, без зависимостей)

```js
// server.js — ЮKassa. Запуск: YOOKASSA_SHOP_ID=... YOOKASSA_SECRET=... node server.js
import http from "node:http";
const SHOP = process.env.YOOKASSA_SHOP_ID, SECRET = process.env.YOOKASSA_SECRET;
const PLANS = { week:{days:7,price:99}, month:{days:30,price:249}, year:{days:365,price:1790} };
const paid = new Map();                    // в продакшене — база (SQLite/Postgres)

const auth = "Basic " + Buffer.from(SHOP + ":" + SECRET).toString("base64");
const idempotence = () => crypto.randomUUID();

http.createServer(async (req, res) => {
  const url = new URL(req.url, "http://localhost");
  if (req.method === "POST" && url.pathname === "/pay/start"){
    const body = JSON.parse(await readBody(req));
    const plan = PLANS[body.plan] || PLANS.month;
    const r = await fetch("https://api.yookassa.ru/v3/payments", {
      method:"POST",
      headers:{ "Content-Type":"application/json", "Idempotence-Key": idempotence(), Authorization: auth },
      body: JSON.stringify({
        amount:{ value: plan.price.toFixed(2), currency:"RUB" },
        capture:true,
        description:"Клубная карта «Тихая заводь»",
        metadata:{ code: body.code, plan: body.plan },
        confirmation:{ type:"redirect", return_url:"https://ВАШ-ДОМЕН/?paid=1" }
      })
    });
    const j = await r.json();
    return json(res, { url: j.confirmation && j.confirmation.confirmation_url });
  }

  // вебхук: провайдер сообщает об оплате
  if (req.method === "POST" && url.pathname === "/pay/notify"){
    const ev = JSON.parse(await readBody(req));
    // 1) обязательно перепроверить платёж запросом к API по его id
    const chk = await fetch("https://api.yookassa.ru/v3/payments/" + ev.object.id, { headers:{ Authorization: auth } });
    const pay = await chk.json();
    if (pay.status === "succeeded"){
      const { code, plan } = pay.metadata || {};
      if (code && PLANS[plan]) paid.set(code, { plan, at: Date.now() });
    }
    return json(res, { ok:true });
  }

  if (req.method === "GET" && url.pathname === "/pay/status"){
    const code = url.searchParams.get("code");
    const p = paid.get(code);
    if (!p) return json(res, { ok:false, why:"не оплачено" });
    const exp = Date.now() + PLANS[p.plan].days * 86400000;
    return json(res, { ok:true, key:{ plan:p.plan, exp }, token: code + "." + exp });
  }

  res.writeHead(404); res.end();
}).listen(8080);

const json = (res, o) => { res.writeHead(200, {"Content-Type":"application/json","Access-Control-Allow-Origin":"*"}); res.end(JSON.stringify(o)); };
const readBody = (req) => new Promise(r => { let d=""; req.on("data",c=>d+=c); req.on("end",()=>r(d)); });
```

### Подключить сервер к игре

В `rybalka.html` перед подключением `game.js` (или прямо в сборке) указать адрес:

```html
<script>window.RYBALKA_PAY_API = "https://pay.tihayazavod.ru";</script>
```

После этого кнопка «Оплатить» начнёт отправлять игрока на страницу оплаты провайдера,
а «Проверить оплату» — запрашивать ключ. Больше ничего менять не нужно.

## 5. Порядок запуска (по шагам)

1. Оформить **самозанятость** в приложении «Мой налог» (10 минут).
2. Зарегистрироваться у провайдера (**Robokassa** или **ЮKassa**), пройти проверку, получить
   `shopId` и `secret`.
3. Купить домен и выложить игру туда (папка со `index.html` = `rybalka.html`).
4. Поднять сервер из раздела 4 на поддомене `pay.…`, включить HTTPS, прописать адрес в игре.
5. В личном кабинете провайдера указать URL вебхука `https://pay.…/pay/notify`.
6. Проверить тестовым платежом: оплата → возврат `?paid=1` → карта включилась сама.
7. Только после этого выставлять ссылку на игру людям.

## 6. Что важно не забыть

- **Правила магазинов**: если позже пойдёшь в App Store / Google Play, там нужны их внутренние
  покупки (30% и свои правила) — веб-подписка в приложении не пройдёт.
- **Возвраты**: подписка должна уметь закрываться (`__payClear` уже умеет, нужен только экран
  «отменить»), возвраты делать через кабинет провайдера.
- **Чеки**: самозанятому — чек НПД на каждую оплату (у Robokassa автоматически).
- **Ключ игрока**: по нему восстанавливают карту на другом устройстве; сейчас он виден в витрине
  и копируется одной кнопкой.
- **Не хранить секреты в игре**: файл игры публичный, любой ключ внутри него = потерянные деньги.
