# Запуск «Тихой заводи» на Яндекс Играх — пошагово со ссылками

Формат: **шаг → что делаешь → ссылка → чем подтверждается, что шаг сделан.**
Шаги 1–2 — бумажные (без них деньги не придут), с 3-го — технические.
Игра готова: архив лежит в `dist/rybalka-yandex.zip` (3,7 МБ, `index.html` в корне).

| Нужно | Зачем | Сколько стоит |
|---|---|---|

| Яндекс ID | консоль разработчика | 0 ₽ |

## Шаг 1. Оформить самозанятость (1 день)

1. Установи приложение **«Мой налог»**:
   - [iOS](https://apps.apple.com/ru/app/%D0%BC%D0%BE%D0%B9-%D0%BD%D0%B0%D0%BB%D0%BE%D0%B3/id1437514123)
   - [Android](https://play.google.com/store/apps/details?id=ru.lknpd.mynalog)
   - или [веб-версия](https://lknpd.nalog.ru/)
2. Вход по номеру телефона → «Стать самозанятым» → выбрать регион → вид деятельности
   **«Разработка компьютерных игр / услуги в области информационных технологий»** → отправить.
3. Обычно регистрация занимает 10–15 минут, ИНН подтягивается сам.
   Проверить статус: [ЛК самозанятого](https://lknpd.nalog.ru/).

✅ **Готово, если**: в приложении написано «Вы самозанятый», есть ИНН (12 цифр).

> Лимит НПД — 2,4 млн ₽ в год, налог 6% с доходов от физлиц, отчётность нулевая.
> Продажа доступа к своей игре под НПД подходит.

## Шаг 2. Стать разработчиком Яндекс Игр (15 минут + ожидание)

1. Открой консоль: **https://games.yandex.ru/console** — войди Яндекс ID.
2. Заполни профиль разработчика (нажать «Стать разработчиком» / «Создать аккаунт разработчика»):
   - тип: **самозанятый**;
   - ИНН, паспортные данные, контакты.
3. Дождись проверки данных (может занять до пары рабочих дней).
4. Полезные закладки сразу:
   - [Добавление игры (документация)](https://yandex.ru/dev/games/doc/ru/q-and-a/adding-and-editing.html)
   - [Требования к играм](https://yandex.ru/dev/games/doc/ru/concepts/requirements)
   - [Подключить покупки](https://yandex.ru/dev/games/doc/dg/console/connect-purchases.html)
   - [Выплаты и «Единый лицензионный договор»](https://yandex.com/dev/games/doc/en/payments)
   - [SDK: покупки](https://yandex.com/dev/games/doc/en/sdk/sdk-purchases)

✅ **Готово, если**: в консоли доступна кнопка «Добавить игру».

| Статус `approved` | аккаунт подтверждён, больше ничего не нужно |
| Язык для связи | Русский |
| E-mail | `trololo248rus@yandex.ru` — оставить, сюда придут результаты модерации |
| Доп. email / email поддержки игроков | желательно указать второй адрес — его видно игрокам |
| Телеграм | не обязателен; только латиница, цифры, `_` и `@` |
| **Единая лицензионная схема** — «Не подключён» | см. «Шаг 2б» ниже: для самозанятого договор подключается **не кнопкой ЕЛС**, а через виджет **«Самозанятость»** |
| **Монетизация** — «Не подключена» | это про рекламу (РСЯ). Станет «Подключена» после подписания ЕЛС и включения на странице игры; отдельной заявки не нужно |
| Внешняя монетизация | **не подключать** — сторонние платежи на Яндекс Играх запрещены |

Для максимума трафика её оставляют в покое.

Порядок кнопок именно такой: **сначала «Перейти к ЕЛС»**, потом загрузка черновика и включение
покупок — иначе вкладка «Покупки» останется без статуса «Покупки разрешены».

## Шаг 2б. Как подключить договор самозанятому (ЕЛС + «Самозанятость»)

Важно: **пока договор не активен, игру нельзя отправить на модерацию** — платформа не принимает
черновик без подписанного договора. Это и есть причина, почему статус «Не подключён» блокирует всё.

ЕЛС (единая лицензионная схема) = один договор на **рекламу + сторонние сети + инап-покупки**,
и всё это в одной выплате.

### Порядок действий

1. **Убедиться, что самозанятость есть.** [lknpd.nalog.ru](https://lknpd.nalog.ru/) или приложение
   «Мой налог» → статус «Вы самозанятый», есть ИНН.
2. **Консоль → Профиль → Документы → Договор** → виджет **«Самозанятость»** → **«Стать самозанятым»**.
   (Именно этот виджет, а не кнопка «Перейти к ЕЛС» — для физлица/самозанятого путь другой.)
3. Нажать **«Отправить запрос»** — Яндекс проверит статус по ИНН и пришлёт запрос на сотрудничество.
4. **«Мой налог» → Настройки/Прочее → Партнёры** → у Яндекса нажать **«Подтвердить/Разрешить»**.
5. Вернуться в Консоль → **«Проверить»**. Через **1–3 рабочих дня** в
   **Профиль → Документы → Договор** поле **«Тип контрагента»** станет
   **«Физическое лицо (Самозанятый)»**, а ЕЛС — «Active».
6. **Реквизиты для выплат**: **Профиль → Документы → Реквизиты** → откроется Яндекс Баланс →
   указать карту/счёт. ⚠️ ИНН в реквизитах должен **совпадать** с ИНН в «Мой налог», иначе переход
   в самозанятые не пройдёт.

### Что после этого станет доступно

| Было | Станет |
|---|---|
| ЕЛС «Не подключён» | **Active** — один договор на рекламу и покупки |
| «Монетизация: не подключена» | реклама Яндекса включается сразу, сторонние сети — через ЕЛС |
| Вкладка «Покупки» пустая | появляется статус **«Покупки разрешены»** — можно добавлять инапы |
| Модерация | **разблокирована** (без договора черновик не примут) |

### Налоги (самозанятый)

- Ставка **6%** (Яндекс — юрлицо), платить до **25 числа** следующего месяца.
- **Чеки формирует сам Яндекс** и передаёт в ФНС — вручную в «Мой налог» их создавать **не нужно**,
  иначе будут дубли и лишний налог.
- Если чека нет — сначала чат поддержки Консоли, а не ручной чек.

## Шаг 3. Создать черновик и загрузить архив

1. В консоли → **Добавить игру** → откроется вкладка **Черновик**.
2. Загрузить архив **`dist/rybalka-yandex.zip`** (уже собран под платформу: `index.html` в корне,
   манифест, `sw.js`, иконки; внутри — вся игра одним файлом).
3. Дождаться статуса файла **«Файл проверен»** (обычно минуты).
4. Протестировать: в черновике появится ссылка на тестовую версию — открыть её в браузере
   и в мобильном приложении Яндекса, пройти путь «титул → заброс → подсечка → вылов».

✅ **Готово, если**: статус «Файл проверен», игра открывается по тестовой ссылке без ошибок.

### Студия: один знак, много игр

| Файл | Где применять |
|---|---|
| `release/icon-studio-512.png` | логотип разработчика в профиле (круглый, прозрачные углы) |
| `release/icon-studio-512-square.png` | тот же знак квадратом — соцсети, шапки, если прозрачность не примут |
| `release/icon-studio-192.png` | мелкие места: сайт, favicon, аватар |
| `release/studio-mark-v2.png` | исходник 2048 px — из него делаются любые размеры и правки |
| `release/studio-logo-sheet-v2.png` | превью: круг, квадрат, 64 и 32 px, плашка «разработчик» |

Знак: щит с солнцем, волной и домиком — читается и как «рыбалка/вода», и как «ферма/дом»,
и как «пункт выдачи/место». Палитра: `#030D25` глубина, `#F2A03D` солнце, `#FF7A5C` коралл,
`#2ED3C6` бирюза, `#7FD8C0` вода. Иконки игр делаются в этой же палитре — каталог выглядит
как одна семья, но каждая игра со своим героем (рыба, колос, посылка).

⚠️ Название разработчика в профиле (`MaksOn74`) видно игрокам на странице каждой игры.
Если игр будет несколько, лучше заменить на студийное — например **«Тихая гавань»**
(подходит и к рыбалке, и к ферме, и к ПВЗ).

### Почему логотип разработчика — не иконка игры

| Где | Что показывается | Файл |
|---|---|---|
| Профиль разработчика (`games.yandex.ru/profile`) | один знак на все игры, в круглом виде | `release/icon-studio-512.png` |
| Страница игры в каталоге | своя иконка игры | `release/icon-512.png` (рыбалка) |
| Внутри игры / PWA | иконка установки | `pwa/icons/icon-512.png` |

Если игр станет несколько — знак студии менять не нужно, а иконки игр добавляются каждая своя.
Именно поэтому рыболовную иконку в профиль ставить не стоит: следующая игра («Охота», «Садовод»)
не должна выглядеть как рыбалка.

## Шаг 4. Заполнить карточку игры (важно для модерации)

Поля должны совпадать во всех местах — название на иконке, в карточке и внутри игры
(у нас внутри «РЫБАЛКА · Тихая заводь»).

| Поле | Что вписать |
|---|---|
| Название | **Тихая заводь: рыбалка** |
| Категория | Игры → Симуляторы / Рыбалка |
| Описание | 105 видов рыбы, 8 водоёмов, сезоны и лёд, погода как физика, квесты и клуб |
| Иконка | `release/icon-512.png` (круглая, готова под требование 512×512 PNG) |
| Скриншоты | 3–5 из папки `screenshots/` (лучше `f87-hud.jpg`, `f88-title2.jpg`, `f87-winter.jpg`, `f87b-layers.jpg`) |
| Возрастной рейтинг | 6+ (нет крови, азартных механик и покупок за реальные призы) |
| Ориентация | вертикальная, мобильная адаптация включена |
| Язык | русский |

⚠️ В игре **нет** вывода реальных денег, призов и промокодов — это прямо запрещено требованиями.

## Шаг 5. Включить монетизацию и покупки

1. В консоли на странице игры → **Монетизация** → включить рекламу (РСЯ) и покупки.
2. Подписать **Единый лицензионный договор** (для самозанятого — через консоль, кнопка «Перейти в ЕЛД»).
   Документ: [условия выплат](https://yandex.com/dev/games/doc/en/payments).
3. Открыть вкладку **Покупки** и создать **ровно эти 5 товаров** (ID критичны — они зашиты в игру):

| ID товара | Название | Цена | Тип |
|---|---|---|---|
| `pass_week` | Клубная карта · неделя | 99 ₽ | нерасходуемый |
| `pass_month` | Клубная карта · месяц | 249 ₽ | нерасходуемый |
| `pass_year` | Клубная карта · год | 1790 ₽ | нерасходуемый |
| `pearls_100` | 100 жемчуга | 99 ₽ | расходуемый |
| `pearls_500` | 500 жемчуга | 399 ₽ | расходуемый |

4. В товарах должны быть картинка, название и состав — модерация сверяет их с игрой.

✅ **Готово, если**: на вкладке «Покупки» статус **«Покупки разрешены»**.

## Шаг 6. Отправить на модерацию

1. Вкладка **Черновик** → **Отправить на модерацию**.
2. Сроки: обычно **3–5 рабочих дней**; ночью модерация не работает.
   Если включить «Отсроченная публикация» — сможешь сам нажать «Опубликовать».
3. Результат придёт на почту Яндекс ID и появится в консоли:
   - **Проверен / Опубликовано** → игра в каталоге;
   - **Отклонён** → в письме причины, правишь и отправляешь снова (после отклонения
     повторная отправка доступна не сразу — время даётся на исправления).

**Частые причины отказа** (проверь до отправки):
- не встроен SDK (у нас встроен, определяется автоматически);
- игра не работает в полноэкранном режиме/на мобильном;
- название или иконка не совпадают с карточкой;
- есть внешние ссылки, вывод денег или призы;
- пустые покупки в игре при активных покупках в консоли (и наоборот).

## Шаг 7. Получать деньги

| Что | Как |
|---|---|
| Источник 1 | **Реклама** (межстраничная и за награду) — доход с показов |
| Источник 2 | **Покупки** (клубная карта, жемчуг) — тебе ~50% дохода после комиссий |
| Источник 3 | **Яндекс Плюс** — начисление за время игры подписчиков |
| Порог выплаты | **3 000 ₽**; если не набралось — переносится на следующий месяц |
| Когда платят | раз в месяц, в течение 20 рабочих дней после отчётного периода |
| Куда | реквизиты из консоли: **Аккаунт → Реквизиты** |
| Налог | 6% (НПД), удерживается автоматически |
| Статистика | консоль → «Метрики монетизации» (доход, ARPDAU, показы, покупки) |

Документ по выплатам: [Unified licensing model](https://yandex.com/dev/games/doc/en/payments).

## Шаг 8. Обновления игры (после релиза)

1. Собери новую версию: `python3 build.py` → архив через `dist/pack`.
2. Консоль → игра → **Создать черновик** → загрузить новый архив → «Отправить на модерацию».
3. Обновления идут **3–5 дней**, но в каталоге всё это время работает прежняя версия.
4. В поле «Комментарий разработчика» перечисли изменения — это ускоряет проверку.

## Что уже готово в игре под платформу

- SDK Яндекс Игр подключается автоматически, только на платформе (офлайн-игра не страдает).
- Реклама: межстраничная (не раньше 6-го заброса, не чаще раза в 4 минуты) и за награду (+15 жемчуга).
- Покупки: 5 товаров выше, выдача после оплаты, восстановление при запуске.
- Облачные сохранения: прогресс один на телефоне и компьютере.
- Тесты: `tests/yandex.mjs` и `tests/pay.mjs` — зелёные, ошибок консоли 0.

## Запасной путь (если Яндекс не подойдёт)

Свой домен + Robokassa: почти весь платёж ваш (комиссия 3,4% карта / 3% СБП), но трафик
придётся приводить самому и нужен свой сервер. Подробности и каркас сервера — в `docs/payments.md`.
